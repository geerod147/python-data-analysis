# Python Data Analysis Project

This project analyzes airline passenger data using Python to extract meaningful insights and trends.

## Features
- Reads and processes CSV data
- Calculates total, average, min, and max values
- Identifies peak performance month
- Demonstrates data handling and analysis using Python

## Technologies Used
- Python
- CSV module

## Example Output
Total Passengers: 15426  
Average Passengers: 428.5  
Highest Value: 622  
Lowest Value: 310  
Best Month: AUG  

## How to Run
1. Clone the repo:
   git clone https://github.com/geerod147/python-data-analysis.git
2. Run:
   python data_analytics.py
